# Project Rules

1. Background #F6F7F3
2. White cards with shadow 0 2px 12px rgba(20,30,25,0.06)
3. Primary green #3E7C59
4. Secondary data accent #6C5CE7 (reserve this strictly for investment-related lines/segments in charts, never general UI)
5. Warning #E4572E
6. Success #2FA76B
7. Text #1F2420 with muted #5B655C
8. Rounded corners 20-24px on all cards
9. One font family only (Manrope or Plus Jakarta Sans)
10. Tabular-nums enabled on all numeric text
11. Tailwind: core utility classes only, no arbitrary bracket values
